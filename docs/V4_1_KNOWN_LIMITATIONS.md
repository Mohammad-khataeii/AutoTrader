# V4.1 known limitations

Overall status: PARTIALLY_COMPLETE_WITH_BLOCKERS.

- Security: PostgreSQL 16 CVE-2026-86140 is fixed by a tested local upstream backport; it must be maintained/rebased as vendor packages change. Disabled Grafana still has 2 critical/19 high distinct CVEs. See the exact security disposition; the entire stack is not cleared.
- Deployment: Docker Desktop Linux containers on this Mac are verified locally. No remote VPS, SSH access, domain, TLS termination, firewall, remote host restart, external alert delivery or sustained 24/7 remote operation has been verified.
- Research: no strategy passed validation. Approved members are empty, so ordinary paper execution holds cash. An engineering acceptance fixture is not a validated strategy. No gates were reduced to obtain trading activity.
- Data: Coinbase direct EUR OHLCV is a proxy for Revolut X. Historical venue order books, latency, queue position and historical tick/lot schedules are unavailable. Costs/liquidity are explicit modeled assumptions. Thin pairs have large genuine gaps. Longer BTC/ETH history changes cross-sectional availability over time. No prices or gaps are filled synthetically.
- Statistics: historical test dates have been replayed during engineering and overlap previous studies; they are not newly untouched. Rolling windows overlap. Active-week bootstrap and entry-date independence are approximations; multiple-testing adjustment does not eliminate data mining. Per-asset/regime curves are common-capital portfolio contributions, not standalone investable strategies. No predictive edge or profitable deployment is established.
- AI: mock mode is verified. No real paid model entitlement, billing, provider accuracy or incremental return has been verified. Token-derived costs are estimates until invoice reconciliation. Unknown charges remain held. Internal conservative reservations cannot guarantee an external invoice never exceeds USD 10 after provider pricing/usage errors; such overruns fail closed and require review.
- Reliability: worker retry/lease fencing and process restart are tested. Health checks alone do not restart an unhealthy live process. Compose restarts exited processes. Host sleep, provider rate limits and database outages can delay monitoring; stale books never become fabricated fills. There is no independent remote supervisor or external paging.
- Pilot: a local RESEARCH_ONLY pilot was started during browser acceptance. Thirty days have not elapsed. Local acceptance outages will appear in its observations; it is not the user's VPS experiment. Daily exports after UTC midnight are implemented/tested but no actual month of daily reports exists. Benchmark observations require new completed candles. Observation gaps are not exact downtime measurements.
- Operations: cache, observations and incidents need disk monitoring, backup and retention planning; automatic destructive cleanup is intentionally absent. Optional monitoring remains stopped. Research volume synchronization must use the verified command so pointers have the application owner's permissions.
- The original financial journal, fills, reserves, stops, partial targets, EUR 500 capital and hard loss/exposure gates are preserved. No real account balance is represented by the virtual account. Database administrators remain trusted.

The local acceptance scanner is configured for three markets to bound public API load; the default is eight. Local cadence/health evidence therefore does not establish full-universe throughput or a remote 24/7 service level.
